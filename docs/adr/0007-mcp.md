# ADR-0007: MCP-Server im API-Container

Status: angenommen · 28.10.2026

## Kontext
Auswertungen laufen extern, zum Beispiel über Claude oder die Fitness-App. Der MCP-Server soll keine eigene Logik haben.

## Entscheidung
- Der MCP-Server läuft im API-Prozess, per Streamable HTTP unter `/mcp`, mit dem offiziellen Python-SDK `mcp`. Er ruft dieselben Services wie die REST-API.
- Lesende Werkzeuge: `search_food`, `get_food`, `list_entries` (Zeitraum) und `daily_summary`.
- Schreibend ist nur `log_meal`.
- Die Fitness-App bindet BISS als eigenständigen Dienst über die REST-API an. Tagesziele setzt sie über `PUT /goals/{date}`. Es gibt keine gemeinsame Datenbank.

## Folgen
- Ein Dienst weniger zu betreiben.
- Weitere schreibende Werkzeuge brauchen eine Entscheidung.
